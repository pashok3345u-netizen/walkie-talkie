# Walkie-Talkie

Голосовые звонки с друзьями, как в Discord: каналы по коду, стримы экрана, камера, аккаунты, друзья,
личные сообщения. Программа для Windows 10/11 на Electron. Внутри программы и в коде встречается старое
название «Рация» / Racia — это та же программа.

## Общение с владельцем

- Владелец не программист. Объяснять простыми словами, по-русски, без жаргона.
- **Перед `git push` (любой выкладкой на GitHub) — спросить владельца.** Коммитить локально можно.
- Задачи делаются по одной: после каждой владелец проверяет, потом выпускаем версию.
  Перед крупной задачей сначала показать план.

## Что лежит в репозитории

https://github.com/pashok3345u-netizen/walkie-talkie — он же источник автообновления, поэтому всё,
что попадает в `main`, сразу видят программы друзей.

- `update.json` — что проверяет программа: номер версии, minEngine, notes, список файлов с SHA-256.
- `v<N>/` — файлы, которые программа скачивает при обновлении (всё из `app/`, кроме файлов установщика).
  Хранится только папка самой новой версии.
- `Walkie-Talkie.zip` — установщик для новых людей (install.bat, install.ps1, uninstall.ps1,
  Прочитай.txt и папка app).
- `src/` — **исходники**: ровно то, что лежит в Walkie-Talkie.zip. Сборки нет, это обычные HTML/JS.
  Правим здесь.
- `ice.json` — адрес и логин TURN-сервера. Программа (с версии 16) читает его при запуске,
  поэтому поменять пароль или сервис можно без выпуска версии (см. «Звонки»).
- `tools/release.py`, `tools/release.ps1` — выпуск новой версии (см. ниже).
- `tools/test-harness/` — тестовый запуск программы в отдельной копии Electron (см. «Как тестировать»).
- `.gitattributes` = `* -text`: git не трогает концы строк, иначе SHA-256 файлов разъедутся.

## Исходники (`src/`)

- `install.bat` → `install.ps1` — установщик: качает Electron 44.7.0 (GitHub, запасной — npmmirror),
  сверяет SHA-256, ставит в `%LOCALAPPDATA%\Racia\engine\WalkieTalkie.exe` (+ `resources\app`),
  собирает `RaciaKeys.exe` через `csc.exe` из .NET 4, делает ярлыки и запись в «Установленных приложениях».
- `uninstall.ps1` — удаление (вместе с настройками в `%APPDATA%\Racia`).
- `app/loader.js` — точка входа (`package.json` → `main`). Выбирает, какую версию запустить: самую новую
  целую из `%APPDATA%\Racia\updates\<N>` (файлы сверяются с manifest.json по SHA-256) или ту, что пришла
  с установщиком. Если новая версия упала при запуске или не открыла окно — помечается плохой, откат.
- `app/main.js` — Electron: окно (`loadFile` → страница открыта как file://), разрешения, свой выбор
  экрана/окна для стрима (со звуком компьютера через loopback), глобальные клавиши через помощника
  `RaciaKeys.exe` (исходник `RaciaKeys.cs`), вход через Google (временная страничка на localhost
  в обычном браузере), ссылки `racia://`. Стоит `requestSingleInstanceLock`, имя приложения `Racia`.
- `app/preload.js` — мостик `window.racia` между страницей и main.js (только перечисленные функции).
- `app/index.html` — весь интерфейс и звонки, один `<script type="module">`. Разделы помечены
  комментариями `// ---------- название ----------` (настройки, комната и её правила, битрейт,
  соединение hi-fi, вход в канал, стримы, микрофон, устройства, статусы, камера и экран, плитки,
  список людей, пинг и потери, горячие клавиши, мостик к social.js `window.RaciaCall`).
  Отладка: F12 в программе; с `?debug` в адресе доступен `window.__racia`.
- `app/social.js` — аккаунты (вход через Google), профили, друзья, личные сообщения, админка.
  Firebase, проект `walkie-talkie-01`. Работает только в программе. Права доступа задают правила
  Firestore (firestore.rules) — в репозитории их нет (там почты админов), они в консоли Firebase.
  Копия — в `private/` (в .gitignore): `firestore.rules` (новые), `firestore.rules.old` (прежние).
  Правила меняет только владелец, вставкой в консоль; перед этим — `tools/rules-test` (см. «Как тестировать»).
- `app/i18n.js` — английский интерфейс: словарь «русская строка → английская», подменяет текст на лету
  (MutationObserver). **Каждую новую русскую надпись (текст, placeholder, title, aria-label) добавлять
  в словарь.** То, что пишут люди (имена, сообщения), помечать `translate="no"`.
- `app/wt-denoise.js` — шумодав: RNNoise 0.2 (WebAssembly из jitsi/rnnoise-wasm) + голосовой гейт
  в AudioWorklet. Режимы: Выкл / Обычный / Сильный.
- `app/updater.js` — автообновление: через 8 с после запуска и потом раз в 3 часа читает `update.json`
  (raw.githubusercontent.com, запасной — cdn.jsdelivr.net), качает `v<N>/`, сверяет SHA-256,
  собирает новый RaciaKeys.exe и предлагает перезапуститься. Репозиторий берётся из `update-source.json`.
- `app/version.json` (`version`, `engine`), `app/package.json` (`version` = `<N>.0.0`).
- Шрифты `wt-*.woff2`, иконки `wt.ico` / `racia.ico` (запасная, для старых ярлыков).

Файлы `loader.js`, `package.json`, `version.json` ставит **только установщик** — обновление их не меняет.
Поэтому менять их можно лишь так, чтобы старые копии продолжали работать с новыми файлами.

Комментарии в коде: в index.html — по-английски, в main.js / loader.js / updater.js / social.js —
по-русски. Писать в стиле окружающего кода.

## Звонки

- Прямые соединения WebRTC через Trystero: `@trystero-p2p/nostr@0.25.4` с jsdelivr
  (`LIB_URL` в index.html). Друзья находят друг друга через nostr-релеи (`defaultRelayUrls`).
- Канал = код (3–12 латинских букв/цифр). `joinRoom({ appId: 'racia-voice-v4', password: 'racia:' + код,
  rtcPolyfill: HiFiPC, relayConfig }, код)`.
- Действия (`room.makeAction`): `info` (имя, микрофон, камера, стрим, статус, аккаунт), `watch`
  (смотрю / не смотрю твой стрим + качество), `room` (правила комнаты от владельца), `kick`.
  Потоки различаются по `metadata.kind`: `mic`, `camera`, `screen`.
- Класс `HiFiPC` (подкласс RTCPeerConnection, передаётся как `rtcPolyfill`) переписывает SDP:
  Opus 510 кбит/с, стерео; для видео ставит H.264 первым, если видеокарта умеет его кодировать.
- STUN — стандартные из Trystero (stun.l.google.com, stun.cloudflare.com).
- **TURN (с версии 16):** ExpressTURN, бесплатный тариф (1000 ГБ/мес, без карты), сервер
  `free.expressturn.com:3478`, UDP и TCP. Логин постоянный (временные пароли у ExpressTURN платные).
  Владелец и друзья — в России; Cloudflare не берём, его там замедляют.
  - Список берётся из `ice.json` (raw.githubusercontent.com, запасной — jsdelivr), последний удачный
    хранится в localStorage `racia-ice`, запасная копия — `ICE_BUILTIN` в index.html. Передаётся
    в `joinRoom` как `turnConfig`. Вход в канал ждёт свежий список не дольше 3 с.
  - Пароль утёк / сервис заблокировали → поменять `ice.json` и запушить, версия не нужна.
    `"turn": []` выключает сервер. В index.html репозиторий для ice.json прописан прямо (`ICE_URLS`).
  - Худшее при утечке логина — кончится месячный лимит, звонки станут только прямыми. Денег снять нельзя.
  - Прямое соединение по-прежнему пробуется и выигрывает, если работает. Достаточно TURN у одного
    из двоих: новая версия соединяется через свой сервер и со старой 15-й (проверено).
  - В окне «Связь» у каждого друга видно «напрямую» / «через сервер» (по типу кандидата `relay`
    в выбранной паре ICE). Совет про VPN — только если не получилось и через сервер.
  - Скрытый тестовый режим: localStorage `racia-relay-only` = `1` → `iceTransportPolicy: 'relay'`.
- До версии 16 TURN не было, поэтому у некоторых друзей было «нашёлся, но не соединился» без VPN.

## Чат в канале (с версии 17)

Раздел `// ---------- chat in the channel ----------` в index.html, состояние — объект `chat`.
- Без сервера: два новых действия Trystero — `chat` (JSON) и `chatimg` (картинка байтами +
  JSON в `metadata`). Типы в `chat`: `msg` {id, text, re?}, `edit` {id, text}, `del` {id},
  `rx` {id, k, on}, `hreq` (дай историю), `hist` {msgs}. Автор = `uid` из info (MY_UID компьютера).
  Править может автор, удалять — автор или владелец комнаты.
- **Старым версиям не отправлять ничего.** Trystero складывает сообщения неизвестных действий в память
  до выхода из канала. Поэтому в `info` новая версия шлёт `chat: 1` (и `v: 9`), а чат уходит только тем,
  у кого `m.chat` (`chatPeers()`). Для остальных в чате пометка «Не видят чат — старая версия: …».
- История: при первой встрече (первый info с chat: 1) обе стороны шлют `hreq` и получают последние
  100 сообщений (`hist`), без картинок (у картинки остаётся размер → «Картинка недоступна»).
  На диске: localStorage `racia-chat-<код>` (последние 200), список каналов `racia-chat-index`
  (хранятся 30 последних). Картинки только в памяти, не больше 40 одновременно.
- Живые сообщения получают время по часам получателя (часы у друзей бывают сбиты).
- Картинки: вставка Ctrl+V, перетаскивание, кнопка. Сжимаются до 1920 px в WebP (≤ 4 МБ),
  GIF до 4 МБ — как есть. Просмотр — `#chatLight`, «Сохранить» через `<a download>`.
- Упоминания: `@Имя`; подсказка при наборе `@`. Упоминание или ответ на моё сообщение = звук,
  подсветка, «@» на кнопке «Чат». Обычное сообщение — тихий звук не чаще раза в 4 с, только если
  окно не активно или чат закрыт. В «Не беспокоить» без звуков.
- Запреты: владелец — правило `noChat` (новый ключ в RS_KEYS; старый владелец его теряет при передаче),
  администратор — тот же флаг `dm`, что и для личных сообщений (`ADMIN_KEY.noChat = 'dm'`).
  Получатели отбрасывают сообщения запрещённых, у самого запрещённого поле ввода выключено.
- Антиспам: 5 сообщений за 5 с и 40 прочих действий за 10 с от одного друга.
- Глобальные клавиши (RaciaKeys) не включают рацию, если фокус в поле ввода окна и клавиша буквенная
  (`typingKey`) — это касается и личных сообщений.
- Кнопка личных сообщений в нижней панели переименована «Чаты» → «Личные», чтобы не путать с «Чат».
- **Совместимость со старыми версиями.** Друзья какое-то время сидят на старых версиях, а кто-то —
  в браузерной версии (`racia.html`, упоминается в Прочитай.txt). Новая версия должна заходить в те же
  каналы: **не менять appId, пароль, имена и формат существующих действий.** Смена appId или пароля
  уже однажды разделила людей по разным «лобби». Новое добавлять так, чтобы старые версии его просто
  не замечали (новые действия, новые необязательные поля).

## База с версии 18 (одно обновление правил на версии 18–21)

Правила версии 18 владелец вставил 2026-10-10. Что в базе нового (всё в social.js):
- `live/<uid>` — читают **только друзья** (принятая дружба, не заблокирован): `v` (что умеет программа:
  18 = звонки), `at`; дальше в версиях 19–20 — `room` {n, code?} (канал; код — только если друзьям можно
  заходить без приглашения), `game` {n, since}, `note` {t, until?}. Пишется `setDoc(..., {merge: true})`.
- `calls/<пара>` — звонки (см. ниже). `cards/<uid>` — баннер и «о себе» (версия 21).
  `users`: `color` (номер цвета ника), `badges` (меняют только админы). Сообщения: `call: 'missed'`.
- `presence` **не трогать**: старые версии перезаписывают его целиком (`setDoc`).
- **Проверка правил:** при входе `probeV2()` читает `live/<я>`. Отказ «нет прав» = правила ещё старые →
  `S.v2 = false`: новые кнопки скрыты, ничего нового не пишется; повтор раз в 10 мин.

## Звонок другу (с версии 18)

Раздел `// ---------- calls ----------` в social.js. Документ `calls/<пара uid>`: users, from, to, code,
inCall (звонящий уже в этом канале), state, at. `ring` → `ok` / `no` (ответ друга) или `end` (звонящий
сбросил или 30 с без ответа — тогда он же пишет в личку сообщение с `call: 'missed'`).
- Куда заходят: звонящий в канале → к нему; иначе, если принявший в канале, — к принявшему (он пишет
  свой `code` вместе с `ok`); иначе новый случайный код из 10 знаков.
- Правила: только другу, не заблокированным, не забаненному; тому же другу не чаще раза в 15 с;
  принять — только в первые 60 с. Возраст звонка считается по часам сервера (`S.skew` из записи `live`).
- Получатель: окно `#sxRing` с мелодией (WebAudio, без файлов), окно не в фокусе — `APP.flash()` +
  уведомление Windows (`racia.notify` → main.js, беззвучное). «Не беспокоить» — без окна и мелодии.
  Антиспам: с 3-го звонка за 2 мин от одного человека — 10 мин тишины (только «пропущенный»).
- Звонящий: полоска `#sxCallBar` с гудком и «Отменить». Друг без `live.v >= 18` (старая версия) —
  вместо звонка приглашение в канал в личку.
- Уведомления Windows показываются, только если у ярлыка в «Пуске» тот же AppUserModelID (`ICEING.Racia`).
  Установщик его не ставит — `fixShortcut()` в main.js дописывает при запуске (только если ярлык ведёт
  на этот же exe — тестовые копии ярлык не трогают).

## «Зайти к другу» (с версии 19)

Раздел `// ---------- "join a friend" ----------` в social.js. Моё: `live/<я>.room` = {n, code?} —
при входе/выходе и смене галочки сразу, смена числа людей не чаще раза в 10 с (`syncRoom`, проверка раз
в 5 с; число — `RaciaCall.info().count`). Пишется `setDoc(..., { mergeFields: ['v', 'at', 'room'] })` —
`merge: true` склеил бы старый `room.code` с новым. При запуске `room` переписывается (стирает
оставшееся после сбоя). Галочка «Друзья могут заходить ко мне без приглашения» — localStorage
`racia-join-open` (`'0'` = выкл, код не пишется вовсе); в профиль её правила базы не пускают.
У друзей канал показывается (`roomOf`), только пока друг «в сети» по presence: после сбоя без выхода
строка висит до 2,5 мин, пока presence не устареет.

## «Играет в…» и свой статус (с версии 20)

- **Поиск игры** — раздел `// ---------- games ----------` в index.html: раз в 20 с `racia.processes()` →
  main.js спрашивает RaciaKeys командой `procs` (ответ одной строкой `procs имя|имя|javaw=заголовок`,
  UTF-8; ~3 мс; только имена программ и заголовки окон, `Process.GetProcesses` + `EnumWindows` —
  в игры не заглядывает). Старый помощник `procs` не знает → через 4 с main.js переходит на `tasklist`
  (кэш 28 с; без заголовков окон, поэтому Minecraft Java так не находится). `apps` — программы с окном,
  для «Добавить свою игру» (без помощника — только ввод имени файла). Новый RaciaKeys.exe собирает
  updater при обновлении; тестовой копии его надо положить в копию папки app (в `src/` exe класть нельзя).
- Список `GAMES` (название, имена exe без .exe в нижнем регистре); свои игры — `settings.games`
  [{exe, n}], проверяются первыми. `settings.showGame` (галочка и в настройках звонка, и в «Профиле»).
- **Свой статус** — `settings.note` {t ≤ 60, until (мс по моим часам, 0 = навсегда)}, сам истекает.
- В звонке: `info.game` {n, s — сколько секунд уже играет} и `info.note` (старые версии не замечают);
  под именем — строка `.act` (статус и игра — по строке). Друзьям: `live/<я>.game` {n, since — время
  сервера, на 30 с раньше: правила не пускают since позже request.time} и `.note` {t, until?}
  (`writeActivity`, `mergeFields`). Видны, пока друг «в сети». Мост: `RaciaCall.activity / setNote /
  setShowGame / setGames / windows`, событие `racia-activity`.
- Тесты: ненастоящие «игры» — копия ping.exe под именем cs2.exe и окно с заголовком (WinForms,
  собранное csc) под именами javaw.exe / hollow_knight.exe.

## Подводные камни (уже наступали)

- Страница открыта через `loadFile` (file://), поэтому модули AudioWorklet грузить **только через
  data: URL** — не файлом и не blob.
- При смене настроек микрофона сначала **остановить старый трек**, потом `getUserMedia` — иначе Chromium
  оставляет старую обработку (эхоподавление).
- `requestSingleInstanceLock` (имя Racia): тестовая копия, запущенная рядом с установленной, сразу
  закроется. Для тестов — отдельная копия Electron 44.7.0 с отдельной папкой userData.
- **Установленную программу не трогать:** `%LOCALAPPDATA%\Racia\engine\WalkieTalkie.exe`
  и `%APPDATA%\Racia` — это рабочая копия владельца.

## Как тестировать

Установленную программу не трогать. Тесты — в отдельной копии Electron 44.7.0:
скачать `electron-v44.7.0-win32-x64.zip` и `SHASUMS256.txt` с
https://github.com/electron/electron/releases/tag/v44.7.0 во временную папку, сверить SHA-256,
распаковать. Electron заодно работает как Node: `ELECTRON_RUN_AS_NODE=1 electron.exe --check file.js`
(так проверять синтаксис; скрипт из index.html вырезать в .mjs).

`tools/test-harness` запускает папку `app` со своей папкой userData (лок единственного экземпляра
не мешает, настройки владельца не задеваются), с ненастоящим микрофоном, сам заходит в канал и
каждые 2 с пишет в JSON статистику: состояние, пара ICE-кандидатов, байты звука, строку из «Связь».
Регистрацию ссылок `racia://` подменяет, чтобы не перехватить их у установленной программы.
Параметры — в шапке `tools/test-harness/main.js`. Обычный набор проверок:
- две копии новой версии в одном канале (код канала случайный, например `zqt12345678`);
- то же с `--relay=1` у обеих (только через TURN), и с `--icefile=ice.json --tcp=1` (TURN по TCP);
- новая с `--relay=1` + нетронутая копия прошлой версии (совместимость).
- чат: сценарии `--do=<сек>:<файл.js>` нажимают кнопки и пишут в поле (DOM-событиями: `input`,
  клик по `#chatSend`, `keydown` ArrowUp/Enter; картинка — `DataTransfer` → `#chatFile.files`),
  `--shot` + чтение PNG — проверка вида в трёх темах и на английском (`--theme`, `--lang`).
  `document.hasFocus()` у тестовых окон обычно false — непрочитанные не сбрасываются, это нормально.
Для проверки владельцем — `--manual=1`: настоящий микрофон, окно с заголовком «ТЕСТОВАЯ КОПИЯ».

**Аккаунты без настоящей базы** (звонки, друзья): эмулятор Firestore (как для правил, ниже) +
`fb-seed.js` (правила, профили, дружбы: `--users=alice:Алиса,bob:Боб --friends=alice+bob --avatars=1`),
потом копии с `--fb=127.0.0.1:8085/<uid>` — вход без Google, social.js ходит в эмулятор
(localStorage `racia-test-fb`, принимается только адрес этого компьютера). Без `--code` копия сама
в канал не заходит. С `?debug` состояние social.js — `window.__raciaSocial`. В автоматическом режиме
уведомления Windows не показываются, а пишутся в лог. Работает и с `--manual=1`.

**Правила базы** — `tools/rules-test` в эмуляторе Firestore (настоящую базу не трогает).
Нужны Java 21 (Temurin JRE zip) и `cloud-firestore-emulator-v*.jar` (адрес и SHA-256 —
в `src/emulator/downloadableEmulatorInfo.json` репозитория firebase-tools), всё во временной папке.
- Эмулятор: `java -Duser.language=en -Duser.country=US -jar emu.jar --host 127.0.0.1 --port 8085
  --project_id demo-wt` (без `-Duser.language=en` на русской Windows падает на тексте ошибки).
- `electron.exe tools/rules-test --rules=private/firestore.rules [--old=1] [--slow=1]`.
  Шаги `[old]` — то, что делают старые версии (должно работать всегда), `[new]` — новое.
  `--old=1` — прогон на прежних правилах: всё новое должно быть отклонено (так новая версия понимает,
  что правила ещё не обновлены). Почты админов скрипт берёт из файла правил, вместо `PASSWORD_HASH`
  подставляет отпечаток тестового пароля.
- Каждому тестовому человеку — свой адрес `<имя>.localhost`: браузер держит не больше 6 соединений
  на один адрес, иначе седьмой зависает.

## Выпуск новой версии

1. Поднять номер в `src/app/version.json` (`version`) и `src/app/package.json` (`version`: `<N>.0.0`).
2. Из корня репозитория:
   `powershell -NoProfile -ExecutionPolicy Bypass -File tools\release.ps1 src . "что нового"`
   (или `python tools/release.py src . "что нового"`, если есть Python). Скрипт кладёт файлы `app/`
   (кроме loader.js, package.json, version.json и `*.exe`) в `v<N>/`, удаляет старые `v*`, пишет
   `update.json` и пересобирает `Walkie-Talkie.zip` из **всего** содержимого `src/`.
   Значит, в `src/` не должно лежать ничего лишнего (собранный RaciaKeys.exe, тестовые файлы).
   release.ps1 проверен на версии 15: update.json и файлы v15 совпали с release.py байт в байт.
   Архив от release.ps1 помечен как сделанный в Windows (made-by host 0), имена — UTF-8 с флагом.
   Проводник («Извлечь всё»), 7-Zip и WinRAR показывают `Прочитай.txt` правильно; `unzip` из Git Bash
   портит это имя — проверять архив проводником (Shell.Application → CopyHere), а не unzip.
3. Проверить, что SHA-256 в update.json совпадают с файлами в `v<N>/`, закоммитить,
   **спросить владельца** и только потом `git push`.

На компьютере владельца **нет Python и Node** (python.exe — заглушка Microsoft Store).
Русский текст `notes` передавать из PowerShell (из bash кодировка может побиться).
