# Walkie-Talkie

Голосовые звонки с друзьями: каналы по коду, стримы экрана, камера, друзья и личные сообщения. Программа для Windows 10/11.

## Как установить

1. Скачай [Walkie-Talkie.zip](https://github.com/pashok3345u-netizen/walkie-talkie/raw/main/Walkie-Talkie.zip).
2. Распакуй архив (правой кнопкой → «Извлечь всё»).
3. Запусти `install.bat`. Если Windows покажет синее окно «Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае».

Установщик один раз скачает движок программы (около 115 МБ). Ярлык «Walkie-Talkie» появится на рабочем столе и в меню Пуск.

## Обновления

Ставить заново не нужно. Walkie-Talkie сама раз в несколько часов заглядывает сюда, скачивает новую версию и предлагает перезапуститься.

## Что здесь лежит

- `Walkie-Talkie.zip` — установщик последней версии.
- `update.json` и папка `v<номер>` — файлы, которые программа скачивает при обновлении. Каждый файл сверяется по контрольной сумме.
- `src/` — исходники программы (то же, что внутри `Walkie-Talkie.zip`).
- `tools/release.py` — сборка новой версии для этой папки.
